# Definiciones de projecto en solidity
  1. crear directorio sc, ese sera el workspace de todo el projecto
  2. iniciar projecto con foudry en el directorio creado sc
  3. utilizar la libreria openzeppelin
  4. utilizar anvil para todas las ejecuciones
  5. utilizar siempre cuentas de anvil en todos los casos 

# Tests Funcionales Exhaustivos
- crea test sobre todos los smartcomtract de la dao
- crear un directorio docs
- cuando finalizes la ejecucion de test, crea un reporte en markdown de las tareas realizadas y dejalo en docs
